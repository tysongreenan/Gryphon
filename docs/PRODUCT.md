# Gryphon — Product Overview

## Positioning

**Gryphon is the reliability layer for authenticated web access for AI agents.**

It sits next to Browserbase (and similar tools) the same way Browserbase sits next to raw browser automation: it makes a hard, failure-prone capability reliable and easy to use.

---

## One-sentence description

Gryphon gives AI agents reliable logged-in sessions and a clean way to request human help when authentication is required.

---

## Core Promise

> Your agents stop dying on logins and 2FA.

---

## What Gryphon is

- A session + escalation service for agents
- MCP-native and API-friendly
- Focused exclusively on authentication reliability

## What Gryphon is not

- An agent framework
- A general browser automation platform
- A collection of high-level site actions (LinkedIn messaging tools, Gmail triage tools, etc.)
- A full enterprise identity platform (in the early stages)

---

## Primary Interfaces

1. **MCP tools** (preferred for agents)
2. **REST API**
3. **Dashboard** (for humans to manage connections and view history)

---

## Key Concepts

| Concept              | Meaning                                              |
|----------------------|------------------------------------------------------|
| Session              | An authenticated browser state that an agent can use |
| Escalation           | A request from an agent for human help with auth     |
| Connected Site       | A site the user has previously authenticated with    |
| Resolution           | The human completing the required auth step          |

---

## Why the name Gryphon?

The gryphon is a mythical guardian — part lion, part eagle — traditionally a protector of treasure and valuable things.  
Gryphon protects the authenticated state of agents so they can continue their work without constant human babysitting.
